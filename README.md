# Spotify Songs Exploratory Data Analysis (EDA)

## Project Overview
This project explores a Spotify songs dataset using Python to understand music trends, song popularity, audio features, and differences between music genres.

## Objectives
- Analyze song popularity and duration.
- Explore audio features such as danceability, energy, and loudness.
- Compare explicit and non-explicit songs.
- Study patterns across different music genres.
- Visualize the data to identify useful insights.

## Dataset
The dataset contains **114,000 rows and 21 columns**, including track names, artists, albums, genres, popularity scores, and audio features.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed
- Data cleaning and handling missing values.
- Statistical summary of numerical columns.
- Genre-wise analysis.
- Popularity and duration analysis.
- Correlation analysis between audio features.
- Data visualization using graphs and charts.

## Key Findings
- The dataset contains 114 different genre labels.
- The average song popularity is approximately 33 out of 100.
- The average track duration is around 3.8 minutes.
- Some track IDs appear more than once across the dataset.
- Instrumentalness has a weak negative correlation with popularity in this dataset.

## Project Files
